# Scripts catalog

**As of 2026-11-02.**

“Test coverage” and “documentation” describe direct matches found in the repository inventory;
they are not claims of complete behavioral coverage. For entries marked no direct test, the
related evaluation helper may still have tests. Provider keys stay in the local environment;
never put them in command arguments.

`scripts/` retains the documented `python -m scripts.<name>` commands as CLI wrappers.
Operational logic lives under `app/`; completed experiment logic lives under
[`evaluation/studies/`](../evaluation/studies/README.md). Application and evaluation modules
must not import from `scripts/`, and script modules must not import other script modules.
Set up the project with `uv sync --all-extras` as described in [Contributing](../CONTRIBUTING.md);
CI installs from `uv.lock`. Use `uv add` for project dependencies rather than `pip install`.
